# 🔬 AI-Powered Forensic Triage & Postmortem Intelligence System

A next-generation forensic intelligence platform combining physical forensic evidence with digital evidence into synchronized investigative layers using AI-powered reasoning.

## 🧠 Core Innovation: "Digital Stratigraphy"

Unlike existing forensic systems that separately analyze pathology reports or digital evidence, this platform introduces a **unified multimodal forensic intelligence architecture** that semantically correlates autopsy findings, digital evidence, CCTV metadata, IoT telemetry, and behavioral anomalies into a legally explainable investigative graph using AI-powered reasoning.

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| **Multimodal RAG** | AI reads text, understands images, correlates evidence, generates explainable findings |
| **FEAT Multi-Agent System** | 7 specialized AI agents (Autopsy, Timeline, CCTV, Toxicology, Correlation, Explainability, Risk) |
| **Evidence Graph Intelligence** | Property graph database correlates suspects, devices, locations, and digital traces |
| **Dual-Mode TOD Estimation** | Henssge nomogram + metabolomic AI for early and late phase estimation |
| **SHAP + LIME Explainability** | Legally defensible AI with full factor attribution |
| **Blockchain Chain of Custody** | SHA-256 immutable ledger for evidence integrity |
| **Natural Language Queries** | Ask "Who was last seen with victim?" using RAG + Graph reasoning |
| **Risk Scoring Engine** | LSTM + Isolation Forest for anomaly detection and behavioral profiling |

## 🏗️ Architecture

- **Backend**: FastAPI + Python (AI/NLP processing)
- **Frontend**: React + Vite + Tailwind CSS (stunning dark forensic UI)
- **Visualization**: Canvas-based evidence graphs, interactive timelines, radar charts
- **Security**: SHA-256 evidence hashing, chain of custody ledger
